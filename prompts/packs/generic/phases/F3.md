# F3: Why They Differ

Question: **why do the groups or periods differ: count, composition, or level?**

F3 is the only phase allowed to name a cause. The permission is conditional: a cause
counts only if the components add up to the difference F2 measured, with a residual
of zero.

If you cannot make it add up, the honest answer is "tidak dapat diidentifikasi dari
data ini". That is a valid finding. A plausible story that does not reconcile is not.

## Entry condition

F2 produced a contrast with a base. Take the one F2 named as the headline, and copy
its `E-###` rather than re-measuring it:

```
delta = median_a - median_b = 4.4      # group form
delta = value_q3 - value_q2 = -30.4    # time form
```

Every component you produce must sum to this number. If it does not, the
decomposition is wrong, not the total.

If F2 found no material difference, F3 still has work: show which components offset
each other, and close. Do not manufacture a cause for a flat comparison.

## Is the difference real

Before explaining it, check it is bigger than the usual movement.

**Time form.** Print the median absolute period-over-period change across all
periods. If the delta you are explaining is smaller than that median, the change is
within normal variation. Say so, record it, and close the phase.

**Group form.** Print the interquartile range of each group. If the difference
between the two medians is smaller than the IQR of either group, the groups overlap
and the difference is not established as a shift. Say so, record it, and close the
phase.

Closing the phase this way still requires the decomposition finding: the arithmetic
is a measurement even when the difference is noise. Write the decomposition as an
`E-###` with `meta.residual: 0`, and record the claim that the difference matters as
an `H-###` with `status: "rejected"`. The controller needs the `E-###` to let F5 run.

Explaining noise is how a report ends up recommending an action against a movement
that would have reversed on its own.

## Effect size and uncertainty

A difference between two medians is a point estimate. Print its interval.

- Bootstrap a 95 percent interval over at least 2,000 resamples of the difference.
  Print the interval next to the point.
- Print Cliff's delta for the same contrast, with both group sizes. It is the
  effect size for skewed or ordinal data and does not assume normality.
- If the interval crosses zero, the direction is not established. Keep the
  decomposition as the `E-###`, record the direction claim as an `H-###` with
  `status: "rejected"`, and close.
- If `|delta| < 0.147`, the effect is negligible even when the interval excludes
  zero. Say that in the finding.

```
diff=4.4 ci_low=1.1 ci_high=7.9 n_a=220 n_b=310 cliffs_delta=0.31
```

## Step order

| # | Step | Produces |
|---|---|---|
| 1 | restate the delta, and the noise or overlap baseline | `delta=… median_abs_change=…` or `delta=… iqr_a=… iqr_b=…` |
| 2 | effect size and bootstrap interval | `diff=… ci_low=… ci_high=… cliffs_delta=…` |
| 3 | choose the decomposition level the data supports | level A, B, or C, stated |
| 4 | decompose, print every component and the residual | components summing to the delta |
| 5 | rank groups by contribution, if the measure is additive | EP per group, Pareto set, `lainnya` |
| 6 | denominator audit, if the measure is a ratio | numerator change and denominator change |
| 7 | Simpson audit | sign check per large group, standardised value if flipped |

## Level A: count and mean, always available

A total is a count times a mean. This split needs only what F1 already validated.

Time form:

```
count effect = (n_1 - n_0) * mean_0
mean effect  = n_1 * (mean_1 - mean_0)
residual     = delta_total - count effect - mean effect
```

Group form:

```
count effect = (n_a - n_b) * mean_b
mean effect  = n_a * (mean_a - mean_b)
residual     = (total_a - total_b) - count effect - mean effect
```

The residual is zero by construction. Print it anyway, because the reader needs to
see that it is zero and not take your word for it.

Use this level when the measure is additive: a sum of the column means something in
the data's own terms. Do not sum a rate, a score, or an index.

## Level B: composition, when the measure is a rate or a score

When the measure is not additive, the contrast lives in the mean itself, and the
question becomes whether the mix of groups moved or the groups themselves moved.

```
mean        = sum over groups of w_g * mean_g          # w_g = n_g / n
mix effect  = sum over groups of (w_g1 - w_g0) * mean_g0
within effect = sum over groups of w_g1 * (mean_g1 - mean_g0)
residual    = delta_mean - mix effect - within effect
```

This needs one category with 2 to 12 levels, measured in both periods. Level B is a
time contrast: for a group contrast of a non-additive measure there is no composition
to split, so the delta is the level difference, one component, with residual zero.
If no category exists for a time contrast, use the same single-component form and
claim nothing else.

## Level C: quantity and unit value, when both columns exist

```
volume effect    = (units_1 - units_0) * avg_unit_value_0
mix effect       = sum over items of (share_1_i - share_0_i) * (unit_value_0_i - avg_unit_value_0) * units_1
unit value effect = sum over items of units_1_i * (unit_value_1_i - unit_value_0_i)
```

Validation: the three effects must equal the delta within `1e-4` of the delta. Print
the residual. If it is not zero, one of the three is computed on the wrong grain, and
you fix that before writing anything down.

State which level you used. Level A is not a worse answer, it is the answer the data
supports.

## Group attribution

Only for an additive measure, and only for mutually exclusive groups in one
dimension. This is a time contrast: a group contrast already names its two groups, so
there is nothing to attribute inside them.

```
EP_i = (total_1_i - total_0_i) / delta_total
```

- EP sums to 1.0 across the groups of one dimension. Print the sum; if it is not
  1.0, the groups overlap or a row was dropped.
- Sort by absolute contribution, descending.
- Report the smallest set whose absolute contributions reach 80 percent of the total
  absolute movement. Everything after that goes into `lainnya`.
- Pareto drivers plus `lainnya` must equal the delta exactly. Print both sides.

Size is not surprise. A large group moving slightly is expected; a tiny group
collapsing by 90 percent is surprising but is not the cause of anything at the total
level. Only report a group as the driver when its contribution is large. Mention the
small surprising one as an anomaly, not as the reason.

## Denominator audit

Applies when the measure is a ratio: conversion, error rate, share, items per event.

Never report a ratio change without both sides printed:

```
rate=-0.062 count=412 total=3320
```

A ratio can fall while its numerator rises, if the denominator grows faster. The
sentence you write must say which side moved: the numerator fell, or the denominator
expanded. Those are different findings and different actions.

Rule of thumb to print: `delta_ratio ≈ delta_num/num_0 - delta_den/den_0`. If the
printed decomposition does not roughly reproduce the ratio change, one of the two
sides is measured on the wrong population.

## Simpson audit

Do this before you state a direction as the answer.

1. Take the two or three largest groups of the strongest dimension.
2. Compute the delta inside each one.
3. Compare signs with the aggregate delta.
4. If every sign matches, the aggregate direction is safe to state.
5. If a sign flips, the aggregate direction is a mix artifact. Report the subgroup
   values and the mix shift. Do not report the aggregate as the cause.

When the sign flips, quantify it with a standardised value: reweight each group's
mean by the combined group sizes of both periods, then compare. If the standardised
direction differs from the raw direction, the mix shift is the finding.

## Correlation is not a cause

F2 may have printed a correlation. F3 does not promote it.

- Report the correlation with `n` and its interval, and name the third variable that
  could produce it, if one exists in the data.
- If a third column exists, print the correlation inside each level of that column.
  A correlation that disappears inside the strata is a confounded correlation, and
  that is the finding.
- Never write "X menyebabkan Y" from a correlation. Decomposition is the only route
  to a cause in this run.

## Writing the explanation

Three sentences, in this order:

1. The difference and its split: "Median kelompok A 14,2, lebih tinggi 4,4 dari
   kelompok B, terdiri dari 3,1 dari selisih jumlah baris dan 1,3 dari selisih
   nilai, dengan residual 0,0."
2. The driver: "Selisih terpusat pada dua kelompok, yang menyumbang 78% dari total
   selisih."
3. The limit: "Data ini tidak mencatat kondisi pengukuran, jadi penyebab di luar
   kolom yang ada tidak dapat diuji."

No sentence may name a cause that is not one of the computed components. Weather,
policy, seasonality, and maintenance are outside this dataset unless a column records
them. Naming them is invention.

## Chart budget

At most two charts in F3.

| Chart | Worth drawing when |
|---|---|
| waterfall of the delta into components | always, if the components are non-zero |
| scatter with the group split | the finding rests on a correlation or a confounded correlation |

The waterfall is the one chart in this run that a reader will understand at a
glance. Make it exact: the bars must add up to the printed delta, and the residual
bar is drawn even when it is zero.

## Prohibited in F3

- A decomposition whose residual is not printed, or not zero.
- A cause that is not a component of the decomposition.
- External causes: weather, policy, holidays not in the data, maintenance not in the
  data.
- A ratio change quoted without numerator and denominator.
- Percentages of percentages, or a share of a share.
- Reporting a small group as the driver because its percentage change is large.
- Correlating two columns and calling it a cause. F3 decomposes; it does not
  correlate.
- Summing a rate, a score, or an index as if it were a total.

## Exit check

All of these must be true before `advance_phase`:

- the delta restated, with the noise or overlap baseline printed
- effect size and bootstrap interval printed, with both group sizes
- decomposition level chosen and stated, with all components printed
- residual printed and zero, or the decomposition rejected
- EP per group summing to 1.0, with a `lainnya` bucket and both sides reconciled,
  or the reason attribution was skipped
- denominator audit done if the measure is a ratio
- Simpson sign check done on the largest groups, with the outcome recorded
- correlation, if any, reported with `n` and its confounder, never as a cause
- explanation written in three sentences, with the limit named
- `evidence/F3.json` written, one entry per component and one for the driver
- `cannot_answer` updated if any part of the decomposition was not computable
